# StockT — 投資團隊六角色交叉審查與即時數據 BI 儀表板

StockT 是一套全端動態股票查詢與商業智慧（BI）儀表板，內建「投資團隊班長」**六大獨立角色交叉審查引擎**，支援台股上市櫃、ETF 與美股焦點標的（逾 2,380 檔）即時輸入代號查詢與決策分析。

## 核心功能

1. **輸入股票代號即時動態查詢 (`server.js` + `public/app.js`)**
   - 專屬「股票代號查詢」控制列與頂部 `⌘K` 搜尋列，支援台股上市（`.TW`）、上櫃（`.TWO`）、ETF（如 `00631L`、`0050`）與美股（如 `NVDA`、`AAPL`、`TSM`）直接輸入代號或名稱查詢，並保存最近查詢紀錄。
2. **六大獨立角色交叉審查引擎 (`lib/decisionEngine.js` + `data/committee_reports.json`)**
   - **角色 1｜總體經濟分析師** (16%)
   - **角色 2｜技術分析師** (18%)
   - **角色 3｜基本面分析師** (18%)
   - **角色 4｜籌碼分析師** (16%)
   - **角色 5｜風險管理師** (16%)
   - **角色 6｜交易策略師** (16%)
   - 內建 `00631L.TW`（元大台灣50正2）與 `2330.TW`（台積電）完整六角色交叉審查報告，查詢任一其他標的時皆即時運行六角色量化模型並產出班長最終投資決策與紀律交易計畫。
   - 支援在介面上即時新增／移除專案其他角色意見（持久化於 `data/custom_opinions.json`），送出後立即重算班長加權評分。
3. **互動式金融 BI 視覺化 (`public/charts.js`)**
   - **個股 K 線與技術指標**：1M–2Y 互動 K 線、MA5/20/60/240、成交量／RSI(14)／KD(9,3,3) 子圖、停損與支撐壓力參考線、精確十字準星提示。
   - **500 日定期定額歷史試算**：即時回測投入本金、期末市值、報酬率與平均持股成本。
   - **大盤籌碼資金 BI**：加權指數 vs 三大法人現貨買賣超、上市融資維持率（含 160%/150% 警戒線）vs 外資台指期未平倉淨口數。
   - **全市場寬度與熱力圖掃描器**：全市場多空寬度、成交額前 36 大資金熱力圖與 8 種動態選股排行。

## 啟動方式

需要 Node.js 20+（零外部相依套件）：

```bash
npm start
# 或開發熱重載模式
npm run dev
```

啟動後預設監聽 `PORT=3000`。
